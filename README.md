MyMCdroid is a PlayStation 2 Memory Card manager for Android, developed to provide the main features of the original mymc project in a modern mobile interface. The app supports .PS2 files and ARMSX2/PCSX2-compatible Folder Memory Cards, and includes real-time 3D icon previews.
